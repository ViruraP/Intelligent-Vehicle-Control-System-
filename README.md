# Intelligent-Vehicle-Control-System-
This project develops an intelligent vehicle control system using Zhufei Technology hardware and the RT1064 microcontroller. It enables autonomous navigation for tasks like lane following, intersection handling, roundabout navigation, and zebra crossing detection. The system ensures safe and efficient operation in dynamic environments.

This project depends on the official RT1064 SDK and base libraries provided by Zhufei Technology. These libraries are **NOT included** in this repository for licensing and compliance reasons.
You can download the required libraries from Zhufei Technology's official repository:
- **RT1064 Library**: [Download RT1064 Library](https://gitee.com/seekfree/RT1064_Library)
